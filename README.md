# 📊 CSV Data Manager (CSV Manager)

A complete, secure, and responsive system executed entirely in the browser for reading, editing, searching, and exporting CSV files. Focused on high accessibility, modern design, and extreme compatibility with multiple devices.

## 🚀 About the Project

**Note:** This site was developed by a Brazilian programmer, and the application's interface is entirely in **Brazilian Portuguese (PT-BR)**. This is an **Educational Project** created so that people can study, learn from the code, and understand how to build accessible, frontend-only web applications.

The **CSV Manager** was developed to be a lightweight and fast tool, requiring no backend or uploads to external servers (ensuring total data privacy). It manipulates data arrays in real-time using Vanilla JavaScript, offering a fluid interface with smooth animations and an adaptive design.

## ✨ Features

*   **📥 Dual Import:** Load `.csv` files directly via the upload button or paste the raw data into the text area.
*   **🔍 Dynamic Search:** Instantly filter records by typing any term present in the table.
*   **↕️ Smart Sorting:** Sort data by any column (0 to 3), supporting both alphabetical and numerical order.
*   **🗑️ Mass Deletion:** Select multiple records via checkboxes and delete them simultaneously.
*   **💾 Secure Export:** Generate and download a new, updated `.csv` file with your modifications.
*   **📱 Extreme Responsiveness:** Layout designed to work perfectly on Smartwatches, Smartphones, Tablets, Laptops, Desktops, Smart TVs, and even Virtual Reality devices (VR/Meta Glasses).
*   **♿ Integrated Accessibility:** Full support for **VLibras** for translation into Brazilian Sign Language, plus high contrast, `aria-label` tags, and support for older browsers (including Internet Explorer 11).

## 🛠️ Technologies and Libraries Used

*   **HTML5 & CSS3:** Semantic structure and modern styling with fluid typography (clamp) and Flexbox.
*   **JavaScript (Vanilla):** Pure logic focused on performance and compatibility (ES5 flexibilized for older browsers).
*   **[GSAP (GreenSock)](https://greensock.com/gsap/):** Responsible for fluid animations (fade in/stagger) when rendering table rows.
*   **[FontAwesome 6](https://fontawesome.com/):** High-quality vector icons for buttons and interface.
*   **[VLibras](https://www.gov.br/governodigital/pt-br/vlibras):** Official Brazilian government widget for accessibility for deaf users.

## ⚙️ How to Use

This project requires no package installation (like Node.js/NPM) or local servers.

1. Download or clone this repository.
2. Ensure the `index.html`, `style.css`, and `script.js` files are in the same folder.
3. Double-click the `index.html` file to open it in any browser of your choice (Chrome, Edge, Firefox, Safari, Samsung Internet, etc.).
4. Load your CSV and start managing your data!
